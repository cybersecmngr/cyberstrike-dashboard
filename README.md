## 📦 Installation

### Prerequisites
```bash
# Required software
- Node.js 18+
- Python 3.11+
- npm or yarn
```

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/cyberstrike-dashboard.git
cd cyberstrike-dashboard

# 2. Install Node.js dependencies
npm install

# 3. Install Python dependencies
pip3 install -r requirements.txt

# 4. Run development server
npm run dev

# 5. Open browser
# Navigate to http://localhost:3000
```

### Production Build

```bash
# Build for production
npm run build

# Start production server
npm start
```

## 🎮 Usage

### ZENCEFIL PROTOCOL Ultimate Pentest

1. Navigate to **C.C.C (Cyber Combat Center)** section
2. Click on **ZENCEFIL EFENDI** card
3. Enter target URL (e.g., `http://testphp.vulnweb.com`)
4. Click **Launch Attack**
5. Monitor real-time progress through 15 phases
6. View detailed report with expandable findings
7. Download report in JSON/HTML/MD format

http://testphp.vulnweb.com
